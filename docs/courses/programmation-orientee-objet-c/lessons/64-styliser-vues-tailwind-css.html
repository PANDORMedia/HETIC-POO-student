Styliser les vues avec Tailwind CSS

readingDurée : 15 min

Les vues Razor produisent du HTML, mais sans style elles restent brutes. Tailwind CSS permet de les habiller sans écrire de feuille de style à la main.

Le principe : utility-first

Tailwind fournit des petites classes utilitaires que l'on compose directement dans le HTML. Plutôt que d'écrire du CSS dans un fichier séparé, on décrit l'apparence sur l'élément lui-même :

<button class="rounded bg-blue-600 px-4 py-2 text-white hover:bg-blue-700">
  Réserver
</button>

L'avantage : le style reste cohérent (les couleurs et les espacements viennent d'une même échelle) et on n'accumule pas des fichiers CSS qui gonflent au fil du projet. Il existe deux façons de l'installer.

Option rapide : le CDN

Une seule ligne dans la mise en page rend toutes les classes Tailwind disponibles partout. Aucune étape de compilation. Pratique pour démarrer et pour le cours, mais déconseillé en production car le CSS est recompilé dans le navigateur à chaque chargement.

<!-- Views/Shared/_Layout.cshtml, dans le <head> -->
<script src="https://cdn.tailwindcss.com"></script>

<!-- ensuite, dans n'importe quelle vue -->
<h1 class="text-3xl font-bold text-blue-600">Catalogue</h1>

Option de production : la CLI

Pour un vrai projet, on installe Tailwind via npm et on génère un fichier CSS optimisé. On indique à Tailwind où chercher les classes utilisées ; il ne génère alors que le CSS réellement employé (la purge), pour un fichier final de quelques kilo-octets.

npm install -D tailwindcss
npx tailwindcss init

# tailwind.config.js : ou scanner les classes
#   content: ["./Views/**/*.cshtml"]

# wwwroot/css/input.css :
#   @tailwind base;
#   @tailwind components;
#   @tailwind utilities;

# generer le CSS (et le regenerer a chaque modification)
npx tailwindcss -i wwwroot/css/input.css -o wwwroot/css/app.css --watch
<!-- puis on lie le CSS genere dans _Layout.cshtml -->
<link rel="stylesheet" href="~/css/app.css" />

La démo aspnet-mvc utilise cette approche : ses vues sont écrites avec des classes Tailwind.

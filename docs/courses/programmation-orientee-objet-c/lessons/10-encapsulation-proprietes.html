Propriétés auto-implementées

class Film
{
    public string Titre { get; set; }
    public int Annee { get; set; }
    public string Genre { get; set; }

    public Film(string titre, int annee)
    {
        Titre = titre;
        Annee = annee;
    }
}

Suivez le refactoring en live

Narration

La syntaxe { get; set; } crée automatiquement un champ de stockage.

Slide 7 / 13

Propriétés calculées

class Film
{
    public int Annee { get; set; }
    public string Genre { get; set; }

    // Propriété calculée (lecture seule)
    public int Age => DateTime.Now.Year - Annee;

    public bool EstRecent => Annee >= 2020;
}

var f = new Film { Annee = 2022 };
Console.WriteLine(f.Age); // 4
Console.WriteLine(f.EstRecent); // True
Narration

Une propriété calculée ne stocke rien, elle calcule à la volée.

Slide 8 / 13

Validation dans le setter

class Film
{
    private int _annee;

    public int Annee
    {
        get => _annee;
        set
        {
            if (value < 1888 || value > DateTime.Now.Year + 5)
                throw new ArgumentException("Année invalide");
            _annee = value;
        }
    }
}
Narration

Pour valider, on utilise un champ privé + propriété avec logique.

Slide 9 / 13

Film : avant et après

class Film
{
    private int _annee;
    public string Titre { get; set; }
    public int Annee
    {
        get => _annee;
        set
        {
            if (value < 1888) throw new ArgumentException();
            _annee = value;
        }
    }
    public string Genre { get; set; }
    public int Age => DateTime.Now.Year - _annee;
}
Narration

Voici la transformation complète.

readingDuration: 20 min

Guide d'installation .NET 8

Ce guide te accompagne pour installer le SDK .NET 8 sur ton système, configurer ton IDE et créer ton premier projet console. Conserve ce document comme référence tout au long du bootcamp.

1. Installer le SDK .NET 8

Le SDK (Software Development Kit) contient tout ce dont tu as besoin pour compiler, exécuter et publier des applications .NET. Le Runtime seul ne suffit pas pour développer : il permet uniquement d'exécuter des applications déjà compilées.

Vérifie si .NET est déjà installé en ouvrant un terminal :

dotnet --version

Si la commande renvoie 8.x.x, tu es prêt. Sinon, suis les instructions pour ton système.

Windows

Option A : Installeur graphique

  1. Rends-toi sur dotnet.microsoft.com/download/dotnet/8.0
  2. Télécharge le SDK (pas le Runtime seul) pour Windows
  3. Exécute l'installeur et suis les étapes
  4. Redémarre ton terminal

Option B : winget (ligne de commande)

winget install Microsoft.DotNet.SDK.8

Vérifie après installation :

dotnet --version
# Devrait afficher 8.x.x
dotnet --list-sdks
# Liste tous les SDK installés

macOS

Option A : Homebrew (recommandé)

brew install dotnet@8

Option B : Installeur graphique

  1. Télécharge le SDK depuis dotnet.microsoft.com/download/dotnet/8.0
  2. Ouvre le fichier .pkg et suis l'assistant
  3. Redémarre ton terminal

Sur macOS Apple Silicon (M1/M2/M3), le SDK s'installe en version arm64 nativement. C'est la version recommandée.

Vérifie :

dotnet --version
dotnet --info   # Détails complet sur l'installation

Linux (Ubuntu / Debian)

# Ajouter le dépôt Microsoft
sudo apt-get update
sudo apt-get install -y ca-certificates curl gnupg
curl -fsSL https://packages.microsoft.com/keys/microsoft.asc | sudo gpg --dearmor -o /usr/share/keyrings/microsoft.gpg
sudo chmod a+r /usr/share/keyrings/microsoft.gpg

echo "deb [arch=amd64 signed-by=/usr/share/keyrings/microsoft.gpg] https://packages.microsoft.com/ubuntu/22.04/prod jammy main" | sudo tee /etc/apt/sources.list.d/microsoft.list

# Installer le SDK
sudo apt-get update
sudo apt-get install -y dotnet-sdk-8.0

Pour les distributions basées sur RPM (Fedora, RHEL) : consulte la documentation sur docs.microsoft.com.

Vérifie :

dotnet --version

Tu as le choix entre plusieurs environnements. Tous sont gratuits pour ce bootcamp.

Visual Studio Code (recommandé pour le bootcamp)

  1. Installe VS Code
  2. Installe l'extension C# Dev Kit (par Microsoft) depuis le marketplace
  3. L'extension inclut : IntelliSense, debugging, gestion de projets

Visual Studio 2022 (Windows uniquement)

  • Télécharge Visual Studio Community 2022 (gratuit)
  • Lors de l'installation, sélectionne la charge de travail ".NET desktop development"
  • Inclut un debugger avancé, le designer et les templates de projet

JetBrains Rider (toutes plateformes)

  • Télécharge depuis jetbrains.com/rider
  • Licence étudiant gratuite avec une adresse mail académique
  • Excellent refactoring et analyse de code

Peu importe ton choix, le CLI dotnet reste le même partout. C'est lui que nous utiliserons le plus en bootcamp.

3. Créer et exécuter ton premier projet

Ouvre un terminal et tape les commandes suivantes :

# Créer un nouveau projet console
mkdir MonPremierProjet
cd MonPremierProjet
dotnet new console

# Exécuter le projet
dotnet run
# Sortie attendue : Hello, World!

C'est tout. Trois commandes et ton premier programme C# fonctionne.

4. Comprendre la structure du projet

Après dotnet new console, tu obtiens cette arborescence :

MonPremierProjet/
  MonPremierProjet.csproj   # Fichier projet (métadonnées, dépendances)
  Program.cs                 # Point d'entrée de l'application
<!-- MonPremierProjet.csproj -->
<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <OutputType>Exe</OutputType>
    <TargetFramework>net8.0</TargetFramework>
    <ImplicitUsings>enable</ImplicitUsings>
    <Nullable>enable</Nullable>
  </PropertyGroup>
</Project>
// Program.cs (top-level statements)
// En .NET 6+, pas besoin de classe Program ni de méthode Main.
// Le code est écrit directement au niveau du fichier.

Console.WriteLine("Hello, World!");

Points clés à retenir

  • Program.cs est le point d'entrée. Avec les top-level statements (activés par défaut en .NET 8), pas besoin de déclarer une classe Program ou une méthode Main.
  • .csproj décrit le projet : framework cible, type de sortie, options du compilateur.
  • dotnet run compile ET exécute en une seule commande.
  • dotnet build compile sans exécuter (utile pour vérifier les erreurs).
  • ImplicitUsings importe automatiquement les espaces de noms courants (System, System.Collections.Generic, etc.).

CommandeDescription

  • [ ] Créer un projet console avec dotnet new console
  • [ ] Exécuter le projet avec dotnet run
  • [ ] Ouvrir le projet dans ton IDE avec coloration syntaxique C#
  • [ ] Modifier Program.cs et voir le changement après dotnet run

C# et .NET : une courte histoire

readingDurée : 20 min

Avant d'installer quoi que ce soit, prenons cinq minutes pour situer l'outil. Savoir d'où vient C#, ce qu'est .NET et pourquoi les deux existent t'évite pas mal de confusions, surtout celle qui revient le plus souvent : non, .NET ce n'est pas Windows uniquement, et non, .NET Framework et .NET 8 ne sont pas la même chose.

2002 : la naissance

C# et la première version de .NET Framework sortent en février 2002, après deux ans d'annonces. Le contexte de l'époque : Java a le vent en poupe en entreprise, Microsoft ne dispose que de Visual Basic 6, et le web commence à prendre le pas sur les applications Windows classiques. La réponse de Microsoft est .NET : une machine virtuelle maison (la CLR), capable d'exécuter plusieurs langages (C#, VB.NET, F#) qui compilent tous vers un même code intermédiaire, accompagnée d'une grande bibliothèque standard. C# est conçu propre dès le départ, sans la dette d'un langage existant.

.NET Framework, de 2002 à 2019

Pendant dix-sept ans, .NET Framework reste la plateforme de référence : uniquement sur Windows, et livré avec le système. Quelques jalons marquants :

VersionAnnéeApport
1.0 / 1.12002-2003CLR, ASP.NET, WinForms
2.02005Génériques, types nullables
3.0 / 3.52006-2008WPF, WCF, LINQ
4.0 / 4.52010-2012async / await
4.82019Dernière version, la lignée est gelée

Microsoft a annoncé qu'il n'y aurait jamais de .NET Framework 5. Cette lignée est figée à la version 4.8. Tu en croiseras encore en entreprise, en particulier dans la banque et l'assurance.

2016 : le tournant .NET Core

En 2016, Microsoft réécrit .NET de zéro et le publie sous le nom .NET Core 1.0 : open source, et qui tourne aussi bien sur Windows que sur macOS, Linux et dans des conteneurs Docker. C'est un changement de cap complet pour une plateforme jusque-là cantonnée à Windows.

.NET Framework (historique).NET Core puis .NET 5+
Windows uniquementWindows, macOS, Linux, ARM
Fermé, livré avec WindowsOpen source (licence MIT) sur GitHub
Plus de nouvelle version après 4.8Une release par an, cible de tous les projets récents

L'unification : .NET 5 à .NET 10

À partir de .NET 5 (novembre 2020), le mot "Core" disparait : il n'y a plus qu'un seul .NET, avec une nouvelle version chaque mois de novembre. Les versions paires sont des LTS (Long Term Support, trois ans de support), les impaires des STS (dix-huit mois). En entreprise on cible une LTS. Notre version pour ce cours est .NET 8 (LTS, novembre 2023).

C# au fil des versions

Le langage a été conçu par Anders Hejlsberg, déjà à l'origine de Turbo Pascal et de Delphi, et plus tard de TypeScript. Si tu connais TypeScript, beaucoup de réflexes se transposent : typage strict, inférence de type. C# a gagné des fonctionnalités à chaque version :

VersionAnnéeIdée forte
C# 1.02002Classes, héritage, types valeur
C# 2.02005Génériques, nullables
C# 3.02007LINQ, lambdas, var
C# 5.02012async / await
C# 8 / 92019-2020Références nullables, records, top-level statements
C# 122023Constructeurs primaires, expressions de collection

Pourquoi C# aujourd'hui

  • Typé et sûr : le compilateur est strict et les références nullables attrapent une partie des bugs avant l'exécution.
  • Performant : compilation JIT moderne, et compilation native (AOT) pour des perfs proches du C++.
  • Multi-plateforme : Windows, macOS, Linux, ARM, mobile (MAUI), web (Blazor).
  • Écosystème large : NuGet, ASP.NET, Entity Framework Core, Azure, Unity.
  • Demande forte : recherché en France dans la banque, l'assurance, l'industrie et le jeu vidéo (Unity).

Pourquoi la programmation orientée objet

En code procédural, les données et les fonctions sont séparées : on manipule des tableaux parallèles que l'on espère synchronisés, et la logique est éparpillée. Dès que le programme grandit, ça devient difficile à tester et à faire évoluer. La POO regroupe les données et leur comportement dans une même unité, l'objet, qui représente une entité du domaine. Ce n'est pas une règle absolue : c'est un outil pour garder la main sur la complexité quand le code prend de l'ampleur. Le cours s'organise autour de ses quatre piliers :

  • Encapsulation : cacher l'état interne, exposer un contrat (jour 1).
  • Héritage : réutiliser et spécialiser un comportement (jour 2).
  • Polymorphisme : une même interface, plusieurs formes (jour 2).
  • Abstraction : décrire le quoi sans coder le comment (jours 2 et 3).

Héritage

readingDurée : 20 min

L'héritage en C#

L'héritage est l'un des piliers de la POO. Il permet de créer une classe qui réutilise, étend et modifie le comportement d'une classe existante.

La classe parente est la classe de base, la classe enfant est la classe dérivée.

Le principe clé : la relation « est un » (is-a). Un Film est un Média. Une Serie est un Média.

// Syntaxe de base : l'opérateur :
public class Media
{
    public string Titre { get; set; }
    public int Annee { get; set; }

    public string GetInfo() => $"{Titre} ({Annee})";
}

// Film hérite de Media
public class Film : Media
{
    public string Realisateur { get; set; }
    public int DureeMinutes { get; set; }
}

var film = new Film
{
    Titre = "Inception",
    Annee = 2010,
    Realisateur = "Christopher Nolan",
    DureeMinutes = 148
};

Console.WriteLine(film.GetInfo()); // Inception (2010)

Ce qui est hérité

Une classe dérivée hérite de tous les membres publics et protégés de sa classe de base :

  • Propriétés et champs publics / protégés
  • Méthodes publiques / protégées
  • Événements et indexeurs

Ce qui n'est PAS hérité : constructeurs, destructeurs, membres privés.

C# ne supporte que l'héritage simple : une classe ne peut avoir qu'une seule classe de base directe.

// Chaînage des constructeurs avec base()
public class Media
{
    public string Titre { get; set; }
    public int Annee { get; set; }

    public Media(string titre, int annee)
    {
        Titre = titre;
        Annee = annee;
    }
}

public class Film : Media
{
    public string Realisateur { get; set; }
    public int DureeMinutes { get; set; }

    // Obligation d'appeler le constructeur de Media
    public Film(string titre, int annee, string realisateur, int duree)
        : base(titre, annee)
    {
        Realisateur = realisateur;
        DureeMinutes = duree;
    }
}

var film = new Film("Interstellar", 2014, "Christopher Nolan", 169);
Console.WriteLine(film.Titre); // Interstellar

Utilisez protected pour les membres que seules les classes dérivées doivent voir.

// Masquage de méthode avec new
public class Media
{
    public string Titre { get; set; }
    public string GetDescription() => $"Média : {Titre}";
}

public class Film : Media
{
    // 'new' masque la méthode de base
    // Ce n'est PAS du polymorphisme !
    public new string GetDescription() => $"Film : {Titre}";
}

Media media = new Film { Titre = "Dune" };
Console.WriteLine(media.GetDescription()); // Média : Dune

Film film = new Film { Titre = "Dune" };
Console.WriteLine(film.GetDescription()); // Film : Dune

La classe racine object

Toute classe C# dérive implicitement de System.Object. Membres hérités que vous pouvez redéfinir :

  • ToString() : représentation textuelle
  • Equals(object) : comparaison d'égalité
  • GetHashCode() : code de hachage
  • GetType() : type au runtime

Nous verrons la redéfinition dans la leçon Polymorphisme.

// Upcasting et downcasting
Film film = new Film("Parasite", 2019, "Bong Joon-ho", 132);
Media media = film; // Upcasting implicite (toujours sûr)
Console.WriteLine(media.Titre); // Parasite

// Downcasting explicite (peut échouer)
Media m2 = new Film("Amélie", 2001, "Jeunet", 122);
Film f2 = (Film)m2;
Console.WriteLine(f2.Realisateur); // Jeunet

// Pattern matching avec is
if (m2 is Film f)
    Console.WriteLine($"Film de {f.Realisateur}");

// Opérateur as (retourne null si échec)
Film f3 = m2 as Film;
if (f3 != null)
    Console.WriteLine(f3.DureeMinutes);

Classes sealed

Le mot-clé sealed empêche toute classe d'hériter de celle-ci :

public sealed class FilmStreaming : Film
{
    public string Plateforme { get; set; }
}
// Erreur de compilation :
// public class FilmPremium : FilmStreaming { }

Cas d'usage : protéger un comportement critique, optimiser le runtime, ou par conception.

// Exemple complet : hiérarchie Media
public class Media
{
    public string Titre { get; set; }
    public int Annee { get; set; }
    protected int _id;
    private static int _compteur = 0;

    public Media(string titre, int annee)
    {
        _id = ++_compteur;
        Titre = titre;
        Annee = annee;
    }

    public override string ToString() => $"[{_id}] {Titre} ({Annee})";
}

public class Film : Media
{
    public string Realisateur { get; set; }
    public int DureeMinutes { get; set; }
    public string Genre { get; set; }

    public Film(string titre, int annee, string realisateur, int duree, string genre)
        : base(titre, annee)
    {
        Realisateur = realisateur;
        DureeMinutes = duree;
        Genre = genre;
    }

    public override string ToString()
        => $"{base.ToString()} - {Realisateur} ({DureeMinutes} min, {Genre})";
}

public class Serie : Media
{
    public int Saisons { get; set; }
    public int EpisodesParSaison { get; set; }

    public Serie(string titre, int annee, int saisons, int episodes)
        : base(titre, annee)
    {
        Saisons = saisons;
        EpisodesParSaison = episodes;
    }

    public int NombreTotalEpisodes => Saisons * EpisodesParSaison;
    public override string ToString()
        => $"{base.ToString()} - {Saisons} saisons ({NombreTotalEpisodes} épisodes)";
}
MCQ

Quel mot-clé permet à une classe dérivée d'accéder à un membre sans l'exposer aux autres classes ?

  1. private
  2. protected
  3. internal
  4. sealed
Explanation

protected rend le membre accessible dans la classe et ses dérivées, mais pas depuis l'extérieur.

Points clés

  • L'héritage modélise la relation « est un » avec class Derived : Base
  • Les constructeurs dérivés doivent appeler base() pour initialiser le parent
  • protected offre un accès limité aux classes dérivées
  • Le mot-clé new masque un membre (sans polymorphisme)
  • Toute classe hérite implicitement de object
  • sealed verrouille contre l'héritage
  • C# : héritage simple uniquement

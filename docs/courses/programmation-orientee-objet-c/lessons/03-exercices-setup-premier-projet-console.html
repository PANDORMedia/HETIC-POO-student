Exercices : Setup & premier projet console

Mets en place ton environnement et crée ton premier projet .NET. Chaque exercice est progressif : commence par le 1 et avance.

Durée estimée : 40 minutes

Objectif : Avoir un environnement fonctionnel et comprendre le cycle de vie d'un projet .NET.

Exercise

Exercise

Exercice 1 : Vérifier l'installation .NET 8

Ouvre un terminal et exécute :

dotnet --version

Résultat attendu : 8.x.x (version 8 du SDK)

Si tu vois une autre version ou une erreur, suis le Guide d'installation .NET (lesson jumelle) pour ton système d'exploitation.

Exécute aussi :

dotnet --info

Vérifie que tu vois bien net8.0 dans la section des frameworks installés.

Validation : Note la version affichée par dotnet --version.

# Dans le terminal :
dotnet --version
dotnet --info
Solution
# Résultat attendu :
# 8.x.x (où x.x dépend du dernier patch installé)
# Si le SDK n'est pas installé, suivre le guide d'installation.
Exercise

Exercise

Exercice 2 : Créer un projet console

Dans un terminal :

mkdir BootcampFilms
cd BootcampFilms
dotnet new console
dotnet run

Résultat attendu : Hello, World!

Ouvre le dossier BootcampFilms dans ton IDE. Repère les deux fichiers principaux :

  • BootcampFilms.csproj
  • Program.cs

Validation : Tu vois le contenu de Program.cs avec la ligne Console.WriteLine("Hello, World!");

# Dans le terminal :
mkdir BootcampFilms
cd BootcampFilms
dotnet new console
dotnet run
Solution
# Résultat attendu dans le terminal :
# Hello, World!

Exercice 3 : Personnaliser Program.cs

Remplace le contenu de Program.cs par :

string nom = "Ton prénom";
Console.WriteLine($"Bienvenue au bootcamp POO, {nom} !");
Console.WriteLine("Framework : " + typeof(string).Assembly.GetName().Version);

Exécute avec dotnet run.

Résultat attendu :

Bienvenue au bootcamp POO, Ton prénom !
Framework : 8.0.x.x

Validation : Tu vois ton prénom et la version du framework.

string nom = "Ton prénom";
Console.WriteLine($"Bienvenue au bootcamp POO, {nom} !");
Console.WriteLine("Framework : " + typeof(string).Assembly.GetName().Version);
Solution
string nom = "Alice";
Console.WriteLine($"Bienvenue au bootcamp POO, {nom} !");
Console.WriteLine("Framework : " + typeof(string).Assembly.GetName().Version);
// Résultat :
// Bienvenue au bootcamp POO, Alice !
// Framework : 8.0.x.x

Exercice 4 : Explorer la structure du projet

Sans utiliser l'IDE, uniquement en CLI :

  1. Liste les fichiers du projet : ls (macOS/Linux) ou dir (Windows)
  2. Affiche le contenu du .csproj : cat BootcampFilms.csproj
  3. Identifie la valeur de TargetFramework. Que signifie-t-elle ?
  4. Compile sans exécuter : dotnet build
  5. Vérifie le dossier créé : ls bin/Debug/net8.0/

Questions :

  • Quel est le type de fichier généré dans bin/Debug/net8.0/ ?
  • Pourquoi dotnet build est-il utile même si dotnet run compile aussi ?

Validation : Tu peux expliquer ce que contient le dossier bin/.

# Dans le terminal :
ls                  # Liste les fichiers
cat BootcampFilms.csproj  # Affiche le fichier projet
dotnet build       # Compile sans exécuter
ls bin/Debug/net8.0/      # Vérifie le résultat
Solution
# Le dossier bin/Debug/net8.0/ contient :
# - BootcampFilms.exe (Windows) ou BootcampFilms (macOS/Linux) : l'exécutable
# - BootcampFilms.dll : l'assembly compilée
# - Divers fichiers .dll de dépendances
#
# dotnet build est utile pour :
# - Vérifier les erreurs de compilation sans exécuter
# - Générer l'assembly pour un déploiement
# - Accélérer les cycles de développement

Exercice 5 : Ajouter une classe au projet

Crée un nouveau fichier Film.cs dans le dossier du projet :

public class Film
{
    public string titre;
    public int annee;

    public void Afficher()
    {
        Console.WriteLine($"{titre} ({annee})");
    }
}

Dans Program.cs, utilise cette classe :

Film monFilm = new Film();
monFilm.titre = "Inception";
monFilm.annee = 2010;
monFilm.Afficher();

Exécute avec dotnet run.

Résultat attendu : Inception (2010)

Validation : Tu as créé un fichier séparé, instancié un objet et appelé sa méthode.

// Film.cs
public class Film
{
    public string titre;
    public int annee;

    public void Afficher()
    {
        Console.WriteLine($"{titre} ({annee})");
    }
}

// Program.cs
Film monFilm = new Film();
monFilm.titre = "Inception";
monFilm.annee = 2010;
monFilm.Afficher();
Solution
// Film.cs
public class Film
{
    public string titre;
    public int annee;

    public void Afficher()
    {
        Console.WriteLine($"{titre} ({annee})");
    }
}

// Program.cs
Film monFilm = new Film();
monFilm.titre = "Inception";
monFilm.annee = 2010;
monFilm.Afficher();

// Résultat : Inception (2010)

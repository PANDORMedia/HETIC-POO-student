Slide 5 / 14

Le constructeur paramétré

class Film
{
    public string Titre;
    public int Annee;

    public Film(string titre, int annee)
    {
        Titre = titre;
        Annee = annee;
    }
}

Film f = new Film("Inception", 2010);
Console.WriteLine(f.Titre); // Inception

Slide 7 / 14

Surcharge de constructeurs

class Film
{
    public string Titre;
    public int Annee;
    public string Genre;

    public Film(string titre, int annee)
    {
        Titre = titre;
        Annee = annee;
    }

    public Film(string titre, int annee, string genre)
    {
        Titre = titre;
        Annee = annee;
        Genre = genre;
    }
}
Narration

Tu peux définir plusieurs constructeurs avec des signatures différentes.

Slide 8 / 14

Chaînage avec this()

class Film
{
    public string Titre;
    public int Annee;
    public string Genre;

    public Film(string titre, int annee)
    {
        Titre = titre;
        Annee = annee;
    }

    public Film(string titre, int annee, string genre)
        : this(titre, annee)
    {
        Genre = genre;
    }
}
Narration

this() appelle un autre constructeur de la même classe pour éviter la duplication.

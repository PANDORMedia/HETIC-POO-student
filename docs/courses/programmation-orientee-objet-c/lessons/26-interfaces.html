Interfaces

readingDuration: 20 min

Les interfaces

Une interface définit un contrat : un ensemble de membres qu'une classe s'engage à implémenter. Contrairement à une classe abstraite, une interface ne contient pas d'état ni de constructeurs.

La relation est « peut faire » (can-do) : une classe qui implémente IStreamable peut être streamée.

// Définir et implémenter une interface
public interface IStreamable
{
    string Plateforme { get; set; }
    bool EstDisponibleEnStreaming();
    string GetLienStreaming();
}

public class Film : Media, IStreamable
{
    public string Realisateur { get; set; }
    public int DureeMinutes { get; set; }
    public string Plateforme { get; set; }

    public bool EstDisponibleEnStreaming() => !string.IsNullOrEmpty(Plateforme);
    public string GetLienStreaming() => $"https://{Plateforme?.ToLower()}.com/play/{Titre?.Replace(' ', '-')}";
}

Implémentation multiple

Contrairement à l'héritage (limité à une seule classe de base), une classe peut implémenter plusieurs interfaces. C'est le mécanisme principal pourcomposer des comportements en C#.

public class Film : Media, IStreamable, INotable, IExportable
{
    // Doit implémenter les membres de toutes les interfaces
}
// Plusieurs interfaces pour le gestionnaire de films
public interface INotable
{
    double Note { get; set; }
    void AttribuerNote(double note);
    string GetAvis();
}

public interface IExportable
{
    string ExporterJson();
    string ExporterCsv();
}

public class Film : Media, IStreamable, INotable, IExportable
{
    public string Realisateur { get; set; }
    public int DureeMinutes { get; set; }
    public string Genre { get; set; }

    // IStreamable
    public string Plateforme { get; set; }
    public bool EstDisponibleEnStreaming() => !string.IsNullOrEmpty(Plateforme);
    public string GetLienStreaming() => $"https://{Plateforme?.ToLower()}.com/play/{Titre?.Replace(' ', '-')}";

    // INotable
    public double Note { get; set; }
    public void AttribuerNote(double note) => Note = Math.Clamp(note, 0, 10);
    public string GetAvis() => Note >= 7 ? "Recommandé" : Note >= 5 ? "Moyen" : "À éviter";

    // IExportable
    public string ExporterJson() => $"{{\"titre\":\"{Titre}\",\"annee\":{Annee},\"note\":{Note}}}";
    public string ExporterCsv() => $"{Titre},{Annee},{Note},{Realisateur}";
}

Default interface methods (C# 8+)

Depuis C# 8, une interface peut fournir une implémentation par défaut :

public interface INotable
{
    double Note { get; set; }

    // Implémentation par défaut
    string GetAvis() => Note >= 7 ? "Recommandé" : "À éviter";
}

La classe qui implémente l'interface peut utiliser le défaut ou le redéfinir.

Règle pratique : utilisez une interface pour définir un capacité, une classe abstraite pour partager du code et de l'état.

// Interfaces et polymorphisme
// On peut manipuler des objets via leur type d'interface
Film film = new Film
{
    Titre = "Everything Everywhere All at Once",
    Annee = 2022,
    Realisateur = "Daniels",
    DureeMinutes = 139,
    Plateforme = "Netflix"
};

// Polymorphisme par interface
INotable notable = film;
notable.AttribuerNote(8.5);
Console.WriteLine(notable.GetAvis()); // Recommandé

IStreamable streamable = film;
Console.WriteLine(streamable.EstDisponibleEnStreaming()); // True

IExportable exportable = film;
Console.WriteLine(exportable.ExporterCsv());
// Everything Everywhere All at Once,2022,8.5,Daniels

// Listes typées par interface
List<INotable> notes = new() { film, new Serie { Note = 9.2 } };
foreach (var n in notes)
    Console.WriteLine($"{n.Note}/10 - {n.GetAvis()}");

Interfaces et découplage

Les interfaces sont le pilier du découplage en architecture logicielle. En programmant contre une interface plutôt qu'une classe concrète, vous pouvez :

  • Changer l'implémentation sans modifier le code client
  • Tester avec des mocks
  • Appliquer l'injection de dépendances (jour 4)
// Mauvais : couplage fort
public class Catalogue
{
    private Film _film = new(); // Dépendance directe
}

// Bon : couplage faible
public class Catalogue
{
    private readonly INotable _notable;
    public Catalogue(INotable notable) => _notable = notable;
}
MCQ

Combien d'interfaces une classe peut-elle implémenter en C# ?

  1. Une seule
  2. Deux maximum
  3. Autant que nécessaire
  4. Zéro, seules les classes abstraites autorisent ça
Explanation

C# permet l'implémentation multiple d'interfaces, contrairement à l'héritage qui est limité à une seule classe de base.

Points clés

  • Une interface définit un contrat sans état ni constructeur
  • Une classe peut implémenter plusieurs interfaces
  • Les interfaces permettent le polymorphisme : manipuler des objets par leur capacité
  • C# 8+ autorise les méthodes par défaut dans les interfaces
  • Préférez les interfaces pour les contrats, les classes abstraites pour le code partagé
  • Les interfaces sont la base du découplage et de l'injection de dépendances

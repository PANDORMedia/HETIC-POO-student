Exercices : Models & Controllers

codingDurée : 1h

Objectif

Valider le cycle MVC de bout en bout sur un premier projet ASP.NET Core MVC. Pas encore d'injection de dépendances, pas encore de persistance : uniquement des Controllers et des Views. Avant de coder, revoyons trois notions utiles pour ces exercices : le ViewModel, le ModelBinding des formulaires et la validation par DataAnnotations. Pour une application complète déjà assemblee, tu peux te referer a la demo aspnet-mvc.

Rappel : le ViewModel

Une view affiche ce dont elle a besoin, pas plus. Le modèle du domaine doit rester hors d'atteinte de la vue, car il peut contenir des champs sensibles ou techniques. Coupler la view directement au domaine expose ces détails.

// Modele du domaine
class Voiture
{
    public string Marque;
    public decimal TarifJournee;
    public string ConnectionString;
    private int _idInterne;
}

// View couplee au domaine : @model Voiture
// <p>@Model.ConnectionString</p>   // a eviter

La solution consiste à définir un ViewModel dédié, qui ne porte que les propriétés affichees. Le contrôleur projette le modèle du domaine vers ce ViewModel.

// ViewModel dedie
class VoitureCardVm
{
    public string Marque { get; set; }
    public string Modele { get; set; }
    public decimal TarifAffiche { get; set; }
}

// Le controleur projette
var vm = new VoitureCardVm
{
    Marque = voiture.Marque,
    Modele = voiture.Modele,
    TarifAffiche = voiture.TarifJournee
};
return View(vm);

Rappel : formulaires et ModelBinding

Un formulaire HTML envoie ses champs vers une action serveur. Le runtime mappe automatiquement les champs vers les propriétés du paramètre de l'action : c'est le ModelBinding.

<form asp-action="Create" method="post">
    <input asp-for="Marque" />
    <input asp-for="Modele" />
    <input asp-for="TarifJournee" />
    <button type="submit">Creer</button>
</form>
[HttpPost]
public IActionResult Create(VoitureFormVm form)
{
    if (!ModelState.IsValid)
        return View(form);

    var voiture = new Voiture(
        form.Marque, form.Modele, form.TarifJournee);
    _service.Ajouter(voiture);
    return RedirectToAction("Index");
}

Rappel : validation par DataAnnotations

Les règles de validation se declarent par des attributs poses sur le ViewModel. Dans l'action, ModelState.IsValid indique si le formulaire respecte ces règles. Si la valeur est fausse, tu re-renvoies la view : les erreurs y sont déjà attachées.

public class VoitureFormVm
{
    [Required(ErrorMessage = "Marque requise")]
    [StringLength(50)]
    public string Marque { get; set; }

    [Required]
    [StringLength(50)]
    public string Modele { get; set; }

    [Range(1, 9999, ErrorMessage = "Tarif > 0")]
    public decimal TarifJournee { get; set; }
}
<form asp-action="Create">
    <input asp-for="Marque" />
    <span asp-validation-for="Marque"></span>
    <input asp-for="TarifJournee" />
    <span asp-validation-for="TarifJournee"></span>
</form>

Exercice principal : premier controller

Duree indicative : 20 minutes. Pas d'injection de dépendances ni de persistance a cette étape : on valide seulement le cycle MVC. L'énoncé complet est disponible dans le dépôt.

Étapes

  1. Crée le projet et lance-le une première fois.

    dotnet new mvc -n LocationWeb
cd LocationWeb
dotnet run

    Ouvre https://localhost:5001 : tu vois la page d'accueil par défaut.

  2. Dans Models/, crée Voiture.cs.

    public class Voiture
{
    public int Id { get; set; }
    public string Marque { get; set; }
    public string Modele { get; set; }
    public decimal TarifJournee { get; set; }
    public int NbPlaces { get; set; }
    public string TypeCarburant { get; set; }
}

  3. Dans Controllers/, crée VoituresController.cs avec une liste statique en mémoire et deux actions :

    • Index() retourne la liste complète ;
    • Detail(int id) retourne une voiture précise, ou NotFound() si l'id n'existe pas.
  4. Dans Views/Voitures/, crée Index.cshtml qui affiche la liste avec un lien vers le detail de chaque voiture.
  5. Dans Views/Voitures/, crée Detail.cshtml qui affiche la fiche complète d'une voiture, avec un lien retour vers la liste.
  6. Ajoute un lien vers /Voitures depuis la page d'accueil, en modifiant Views/Home/Index.cshtml.
  7. Lance le projet, navigue et vérifie que tout fonctionne.

Bonus

Ajoute une action RechercherParMarque(string marque) accessible via /Voitures/RechercherParMarque?marque=Renault. Elle filtre la liste et réutilise la même view Index.cshtml.

Classes & Objets

Ce document approfondit les concepts présentés dans le deck "Classes & Objets". Il sert de référence pour les exercices et les jours à venir.

Pourquoi la POO ?

En programmation procédurale, tu organisais ton code en fonctions qui manipulent des données isolées. Ça fonctionne pour de petits programmes, mais dès que la complexité augmente, les données et les fonctions qui les concernent se dispersent.

La programmation orientée objet regroupe les données et les comportements dans une seule unité : la classe. Une classe est un modèle (blueprint) qui définit la structure et le comportement. Un objet est une instance concrète créée à partir de ce modèle.

Analogie : la classe est le plan d'une maison. L'objet est la maison construite à partir de ce plan. Tu peux construire plusieurs maisons identiques (objets) à partir du même plan (classe).

Anatomie d'une classe

Une classe contient :

  • Des champs (fields) : les données stockées
  • Des méthodes (methods) : les actions que l'objet peut effectuer
  • Des constructeurs : comment initialiser un objet (vu dans la leçon dédiée)

Voici notre première classe métier pour le gestionnaire de films :

public class Film
{
    // Champs (les données brutes)
    public string titre;
    public string realisateur;
    public int annee;
    public string genre;

    // Méthode (un comportement)
    public void Afficher()
    {
        Console.WriteLine($"{titre} ({annee}) - {realisateur} [{genre}]");
    }
}

Créer et utiliser des objets

Pour créer un objet, on utilise le mot-clé new :

// Création d'un objet Film
Film film1 = new Film();
film1.titre = "Inception";
film1.realisateur = "Christopher Nolan";
film1.annee = 2010;
film1.genre = "Science-Fiction";

// Appel de méthode
film1.Afficher();
// Sortie : Inception (2010) - Christopher Nolan [Science-Fiction]

// Un deuxième objet, indépendant
Film film2 = new Film();
film2.titre = "Parasite";
film2.realisateur = "Bong Joon-ho";
film2.annee = 2019;
film2.genre = "Thriller";

film2.Afficher();
// Sortie : Parasite (2019) - Bong Joon-ho [Thriller]

Types référence : ce qu'il faut comprendre

En C#, les classes sont des types référence. Quand tu écris Film film1 = new Film();, deux choses se passent :

  1. new Film() crée l'objet en mémoire (sur le tas / heap)
  2. film1 stocke une référence (une adresse) vers cet objet, pas l'objet lui-même

Cela a des conséquences importantes :

Film a = new Film();
a.titre = "Dune";

Film b = a;            // b pointe vers LE MÊME objet que a
b.titre = "Dune 2";

Console.WriteLine(a.titre); // Affiche "Dune 2" !
// a et b sont deux références vers le même objet

// Comparaison de références
Film c = new Film();
c.titre = "Dune 2";

Console.WriteLine(a == b);  // True (même objet)
Console.WriteLine(a == c);  // False (objets différents)

Types valeur vs types référence

AspectType valeur (struct)Type référence (class)
StockagePile (stack)Tas (heap)
AffectationCopie la valeurCopie la référence
Exemplesint, double, bool, DateTimestring, Film, tableaux
== par défautCompare les valeursCompare les références

string est un cas particulier : c'est un type référence mais == compare les valeurs pour des raisons de commodité.

Méthodes : comportement des objets

Les méthodes définissent ce qu'un objet peut faire. Elles peuvent accéder directement aux champs de l'objet via this (implicite la plupart du temps) :

public class Film
{
    public string titre;
    public int annee;

    // Méthode sans retour (void)
    public void Afficher()
    {
        Console.WriteLine($"{titre} ({annee})");
    }

    // Méthode avec retour
    public int Age()
    {
        return DateTime.Now.Year - annee;
    }

    // Méthode avec paramètre
    public bool EstDeLaMemePeriode(Film autre)
    {
        return Math.Abs(this.annee - autre.annee) <= 5;
    }
}

La valeur null

Une variable de type référence peut ne pointer vers aucun objet. C'est la valeur null :

Film film = null;

// Attention : appeler une méthode sur null lève une exception
// film.Afficher();  // NullReferenceException !

// Vérification avant utilisation
if (film is not null)
{
    film.Afficher();
}

// Avec l'opérateur conditionnel null (?.)
film?.Afficher();  // Ne fait rien si film est null

// En .NET 8 avec Nullable activé, le compilateur t'aide :
Film? filmOptionnel = null;    // OK, explicitement nullable
Film filmRequis = null;         // Avertissement du compilateur !

Points clés

  • Une classe est un modèle. Un objet est une instance concrète.
  • On crée un objet avec new NomDeClasse().
  • Les classes sont des types référence : l'affectation copie la référence, pas l'objet.
  • Les méthodes définissent le comportement de l'objet et accèdent à ses données.
  • Attention au null : toujours vérifier avant d'utiliser un objet.
  • Dans le gestionnaire de films, chaque Film sera un objet instancié à partir de la classe Film.

Exercices : Encapsulation & Propriétés

Transforme ta classe Film en une classe correctement encapsulée. Chaque exercice te fait progresser vers un code professionnel.

Durée estimée : 60 minutes

Objectif : Savoir protéger l'état d'un objet avec des propriétés, valider les données et utiliser les propriétés avancées.

Exercice 1 : Rendre les champs privés

Reprends ta classe Film. Transforme tous les champs publics en champs private (convention : préfixe _). Ajoute des auto-propriétés public pour chaque champ.

Avant :

public string titre;

Après :

private string _titre;
public string Titre { get { return _titre; } set { _titre = value; } }

Ou plus simplement en auto-propriété :

public string Titre { get; set; }

Mets à jour Program.cs pour utiliser les propriétés (PascalCase) au lieu des champs (camelCase).

Validation : f.titre ne compile plus. f.Titre fonctionne.

public class Film
{
    // Transformer en privé + propriétés
    public string titre;
    public string realisateur;
    public int annee;
    public string genre;
}
Solution
public class Film
{
    public string Titre { get; set; }
    public string Realisateur { get; set; }
    public int Annee { get; set; }
    public string Genre { get; set; }

    public Film(string titre, string realisateur, int annee, string genre = "Non défini")
    {
        Titre = titre;
        Realisateur = realisateur;
        Annee = annee;
        Genre = genre;
    }

    public void Afficher()
    {
        Console.WriteLine($"{Titre} ({Annee}) - {Realisateur} [{Genre}]");
    }
}

// Program.cs
Film f = new Film("Inception", "Nolan", 2010, "Sci-Fi");
f.Afficher();
Console.WriteLine(f.Titre); // OK
// Console.WriteLine(f.titre); // Erreur de compilation !

Exercice 2 : Validation dans le setter

Remplace l'auto-propriété Annee par une propriété complète avec validation. Règles :

  • L'année doit être >= 1888 (premier film de l'histoire)
  • L'année doit être <= année actuelle + 5
  • Si invalide, lève ArgumentOutOfRangeException avec un message clair

Teste avec des valeurs valides et invalides.

Validation : f.Annee = 1800 lève une exception. f.Annee = 2010 fonctionne.

private int _annee;
public int Annee
{
    get { return _annee; }
    set
    {
        // Ajouter la validation
        _annee = value;
    }
}
Solution
private int _annee;
public int Annee
{
    get { return _annee; }
    set
    {
        if (value < 1888)
            throw new ArgumentOutOfRangeException(nameof(Annee),
                $"L'année {value} est avant 1888, la date du premier film.");
        if (value > DateTime.Now.Year + 5)
            throw new ArgumentOutOfRangeException(nameof(Annee),
                $"L'année {value} est trop dans le futur.");
        _annee = value;
    }
}

// Test
Film f = new Film("Test", "Director", 2010);
f.Annee = 2010;   // OK
f.Annee = 1800;   // Exception !
f.Annee = 2050;   // Exception !

Exercice 3 : Propriété calculée

Ajoute une propriété en lecture seule Age qui retourne l'âge du film. Utilise la syntaxe expression-bodied (=>).

Ajoute aussi une propriété EstRecent qui retourne true si le film a moins de 3 ans.

Film f = new Film("Dune 2", "Villeneuve", 2024);
Console.WriteLine(f.Age);       // 2
Console.WriteLine(f.EstRecent);  // true

Validation : Les propriétés calculées retournent les bonnes valeurs dynamiquement.

// Dans Film.cs
public int Age => /* à compléter */;
public bool EstRecent => /* à compléter */;
Solution
public int Age => DateTime.Now.Year - Annee;
public bool EstRecent => Age <= 3;

// Test
Film f = new Film("Dune 2", "Villeneuve", 2024);
Console.WriteLine($"Age : {f.Age}");       // Age : 2
Console.WriteLine($"Récent : {f.EstRecent}");  // Récent : True

Film vieux = new Film("Metropolis", "Lang", 1927);
Console.WriteLine($"Age : {vieux.Age}");     // Age : 99
Console.WriteLine($"Récent : {vieux.EstRecent}"); // Récent : False

Exercice 4 : Init-only et required

Crée une classe Evaluation pour noter un film :

public class Evaluation
{
    public required string Utilisateur { get; init; }
    public required Film FilmEvalue { get; init; }
    public int Note { get; set; }  // 1 à 5, modifiable
    public string Commentaire { get; set; } = "";
}

Teste :

  1. Crée une Evaluation valide avec la syntaxe d'initialisateur
  2. Essaie de modifier Utilisateur après création. Que se passe-t-il ?
  3. Essaie de créer une Evaluation sans Utilisateur. Que se passe-t-il ?
  4. Modifie la Note après création. Ça fonctionne car c'est set, pas init.

Validation : Tu comprends la différence entre set, init et required.

public class Evaluation
{
    // À compléter
}
Solution
public class Evaluation
{
    public required string Utilisateur { get; init; }
    public required Film FilmEvalue { get; init; }
    public int Note { get; set; }
    public string Commentaire { get; set; } = "";
}

// 1. Création valide
Evaluation e = new Evaluation
{
    Utilisateur = "Alice",
    FilmEvalue = f1,
    Note = 4,
    Commentaire = "Super film"
};

// 2. e.Utilisateur = "Bob";  // Erreur de compilation ! init-only
// 3. Evaluation e2 = new Evaluation { Note = 5 };  // Erreur ! required manquant
// 4. e.Note = 5;  // OK ! set est modifiable

// set : modifiable à tout moment
// init : modifiable uniquement à la création
// required : obligatoire à la création

Exercice 5 : FilmCollection encapsulée

Reprends ta classe FilmCollection de l'exercice précédent et encapsule-la correctement :

  1. Le champ films doit être private
  2. Ajoute une propriété en lecture seule Count qui retourne le nombre de films
  3. Ajoute une méthode RechercherParGenre(string genre) qui retourne une List<Film>
  4. Ajoute une méthode Supprimer(string titre) qui retire le film par son titre
  5. La méthode Tous() retourne une copie de la liste (pas la liste interne directement)

Pourquoi ne pas retourner la liste interne directement ?

Validation : La collection est correctement encapsulée. L'appelant ne peut pas modifier la liste interne.

using System.Collections.Generic;

public class FilmCollection
{
    // Encapsuler correctement
}
Solution
using System.Collections.Generic;
using System.Linq;

public class FilmCollection
{
    private List<Film> films = new List<Film>();

    public int Count => films.Count;

    public void Ajouter(Film f)
    {
        films.Add(f);
    }

    public void Supprimer(string titre)
    {
        films.RemoveAll(f => f.Titre == titre);
    }

    public List<Film> RechercherParGenre(string genre)
    {
        List<Film> resultats = new List<Film>();
        foreach (Film f in films)
        {
            if (f.Genre == genre)
                resultats.Add(f);
        }
        return resultats;
    }

    // Retourne une copie pour protéger la liste interne
    public List<Film> Tous()
    {
        return new List<Film>(films);
    }
}

// Si on retournait films directement, l'appelant pourrait faire :
// collection.Tous().Clear(); // Et viderait la liste interne !
// En retournant une copie, on protège l'état interne.

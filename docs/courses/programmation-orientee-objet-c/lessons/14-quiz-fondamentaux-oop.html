quizDuration: 20 min

Quiz : Fondamentaux OOP

Vérifie ta compréhension des concepts du jour. 8 questions, 20 minutes.

Chaque question a une ou plusieurs bonnes réponses. Lis le code attentivement.

MCQTime limit: 1m

Quelle est la différence entre une classe et un objet ?

  1. Un objet est un modèle, une classe est une instance concrète
  2. Une classe est un modèle (blueprint), un objet est une instance concrète créée avec new
  3. Classe et objet sont deux mots pour la même chose
  4. Un objet contient le code, une classe contient les données
Explanation

La classe est le modèle (blueprint) qui définit la structure et le comportement. L'objet est une instance concrète créée à partir de ce modèle avec le mot-clé new.

MCQTime limit: 1m

Que se passe-t-il quand on écrit Film b = a; si a est une variable de type Film ?

  1. b reçoit une copie complète de l'objet pointé par a
  2. b et a pointent vers le même objet en mémoire
  3. Une erreur de compilation car on ne peut pas assigner un objet
  4. b reçoit une nouvelle instance de Film avec les mêmes valeurs
Explanation

Film est un type référence. L'affectation copie la référence, pas l'objet. Les deux variables pointent vers le même objet en mémoire.

MCQTime limit: 1m

Quel est le rôle d'un constructeur paramétré ?

  1. Détruire un objet quand il n'est plus utilisé
  2. Créer un objet en forcant l'initialisation de certains champs
  3. Appeler automatiquement les méthodes de la classe
  4. Hériter d'une autre classe
Explanation

Un constructeur paramétré garantit que les champs obligatoires sont fournis au moment de la création de l'objet, assurant son intégrité dès le départ.

MCQTime limit: 1m

Que fait le chaînage de constructeurs avec :this(...) ?

  1. Il appelle le constructeur d'une classe parente
  2. Il appelle un autre constructeur de la même classe pour éviter la duplication
  3. Il crée une copie de l'objet courant
  4. Il bloque l'accès au constructeur par défaut
Explanation

Le chaînage avec :this() permet à un constructeur d'en appeler un autre de la même classe, évitant la duplication de code d'initialisation.

MCQTime limit: 45s

Quel access modifier rend un membre accessible uniquement depuis la classe elle-même ?

  1. public
  2. protected
  3. private
  4. internal
Explanation

private restreint l'accès au seul membre de la classe qui le déclare. C'est le niveau d'accès le plus restrictif.

MCQTime limit: 1m

Qu'affiche ce code ?

Film f = new Film();
f.Annee = 2010;
Console.WriteLine(f.Age);

Si Age est défini comme : public int Age => DateTime.Now.Year - Annee;

  1. 2010
  2. 0
  3. L'âge du film calculé dynamiquement (ex: 16 si on est en 2026)
  4. Une erreur car Age n'a pas de setter
Explanation

Age est une propriété calculée (expression-bodied). Sa valeur est calculée dynamiquement à chaque accès : année actuelle moins Annee.

MCQTime limit: 1m

Que se passe-t-il si on essaie f.Titre = "Nouveau"; après création avec public string Titre { get; init; } ?

  1. La valeur est modifiée normalement
  2. Erreur de compilation : init-only property
  3. Une exception est levée à l'exécution
  4. La valeur est modifiée mais un avertissement est affiché
Explanation

Le modificateur init permet l'assignation uniquement lors de l'initialisation de l'objet. Toute tentative de modification ultérieure est une erreur de compilation.

Multi-selectTime limit: 1m 30s

Pourquoi encapsuler les champs d'une classe avec des propriétés ?

  1. Pour valider les valeurs assignées
  2. Pour rendre le code plus lent
  3. Pour protéger l'état interne de l'objet
  4. Pour empêcher l'utilisation de la classe
  5. Pour pouvoir changer l'implémentation interne sans casser le code appelant
Explanation

L'encapsulation permet de valider les données, protéger l'état interne et découpler l'implémentation du contrat public. C'est un des piliers de la POO.

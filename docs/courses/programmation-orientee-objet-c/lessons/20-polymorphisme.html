Polymorphisme

readingDuration: 20 min

Le polymorphisme

Le polymorphisme permet à un même appel de méthode de se comporter différemment selon le type réel de l'objet au runtime.

Une variable de type Media peut pointer vers un Film ou une Serie. L'appel à GetInfo() exécute automatiquement la bonne version.

// virtual et override
public class Media
{
    public string Titre { get; set; }
    public int Annee { get; set; }

    // virtual autorise la redéfinition
    public virtual string GetInfo() => $"{Titre} ({Annee})";
}

public class Film : Media
{
    public string Realisateur { get; set; }
    public int DureeMinutes { get; set; }

    // override remplace le comportement
    public override string GetInfo()
        => $"{Titre} ({Annee}) - {Realisateur}, {DureeMinutes} min";
}

public class Serie : Media
{
    public int Saisons { get; set; }

    public override string GetInfo()
        => $"{Titre} ({Annee}) - {Saisons} saison(s)";
}

Late binding (liaison tardive)

Quand une méthode est virtual, la décision est prise au runtime en fonction du type réel de l'objet. C'est le mécanisme de liaison tardive.

Media media = new Film { Titre = "Dune", Annee = 2021, Realisateur = "Villeneuve", DureeMinutes = 155 };
Console.WriteLine(media.GetInfo());
// Appelle Film.GetInfo() bien que la variable soit de type Media
// Polymorphisme avec les collections
List<Media> mediatheque = new()
{
    new Film { Titre = "Inception", Annee = 2010, Realisateur = "Nolan", DureeMinutes = 148 },
    new Serie { Titre = "Breaking Bad", Annee = 2008, Saisons = 5 },
    new Film { Titre = "Parasite", Annee = 2019, Realisateur = "Bong Joon-ho", DureeMinutes = 132 },
    new Serie { Titre = "Dark", Annee = 2017, Saisons = 3 }
};

foreach (var media in mediatheque)
{
    Console.WriteLine(media.GetInfo());
    // Inception (2010) - Nolan, 148 min
    // Breaking Bad (2008) - 5 saison(s)
    // ...
}

// Redéfinir ToString()
public class Film : Media
{
    public string Realisateur { get; set; }
    public int DureeMinutes { get; set; }
    public string Genre { get; set; }

    public override string ToString()
        => $"{Titre} ({Annee}) | {Realisateur} | {DureeMinutes} min | {Genre}";
}

// Console.WriteLine appelle ToString() automatiquement
var film = new Film { Titre = "Blade Runner 2049", Annee = 2017, Realisateur = "Villeneuve", DureeMinutes = 164, Genre = "Sci-Fi" };
Console.WriteLine(film);
// Blade Runner 2049 (2017) | Villeneuve | 164 min | Sci-Fi

Le mot-clé base dans un override

Dans une méthode override, appelez base. pour réutiliser la logique parente :

public override string GetInfo()
{
    return base.GetInfo() + $" - {Realisateur}";
}

Quand NE PAS utiliser override

  • La méthode de base n'est pas virtual
  • La classe est sealed
  • Vous voulez un comportement selon le type de la variable (compile-time), pas de l'objet (runtime)
// Polymorphisme appliqué au gestionnaire de films
public class Media
{
    public string Titre { get; set; }
    public int Annee { get; set; }
    public virtual string GetInfo() => $"{Titre} ({Annee})";
    public virtual decimal CalculerPrix() => 9.99m;
}

public class Film : Media
{
    public string Realisateur { get; set; }
    public int DureeMinutes { get; set; }

    public override decimal CalculerPrix()
        => DureeMinutes > 120 ? 14.99m : 9.99m;

    public override string GetInfo()
        => $"{Titre} ({Annee}) | {Realisateur} | {DureeMinutes} min";
}

public class Serie : Media
{
    public int Saisons { get; set; }

    public override decimal CalculerPrix() => Saisons * 7.99m;
    public override string GetInfo()
        => $"{Titre} ({Annee}) | {Saisons} saison(s)";
}

// Utilisation polymorphique
List<Media> catalogue = new()
{
    new Film { Titre = "Dune", Annee = 2021, Realisateur = "Villeneuve", DureeMinutes = 155 },
    new Serie { Titre = "Severance", Annee = 2022, Saisons = 2 }
};

decimal total = 0;
foreach (var m in catalogue)
{
    Console.WriteLine($"{m.GetInfo()} - {m.CalculerPrix():C}");
    total += m.CalculerPrix();
}
Console.WriteLine($"Total : {total:C}");
MCQ

Si une variable de type Media contient un Film et que Film redéfinit GetInfo() avec override, quelle version est appelée ?

  1. Media.GetInfo() (type de la variable)
  2. Film.GetInfo() (type réel de l'objet)
  3. Les deux sont appelées
  4. Erreur de compilation
Explanation

Le polymorphisme virtual/override résout l'appel au runtime selon le type réel (Film), pas le type de la variable (Media).

Points clés

  • virtual autorise la redéfinition, override l'effectue
  • Le dispatch dynamique choisit la bonne méthode au runtime
  • Fonctionne avec les collections de type de base (List<Media>)
  • ToString(), Equals(), GetHashCode() sont des overrides fréquents
  • base. réutilise la logique parente
  • Le polymorphisme est ce qui rend l'héritage vraiment puissant

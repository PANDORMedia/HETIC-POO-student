Synthèse & Perspectives

slidesDurée : 20 min

Ce que vous savez faire

Ces quatre jours vous ont mené des bases du langage jusqu'à une application web complète. Voici les acquis, regroupés par journée.

Jour Acquis
J1 .NET 8, C#, encapsulation
J2 Héritage, polymorphisme, interfaces
J3 Composition, SOLID, exceptions orientées objet
J4 ASP.NET Core MVC, injection de dépendances, SQLite avec EF Core, Tailwind, projet web complet

Le fil conducteur reste le même du premier au dernier jour : modéliser un domaine avec des objets clairs, séparer les responsabilités, et s'appuyer sur des abstractions pour garder un code testable et evolutif.

Pour aller plus loin

Le projet web couvre l'essentiel d'une application MVC, mais plusieurs sujets meritent une suite. Trois axes sont particulièrement utiles pour passer d'un prototype a une application réelle.

Identite et authentification

ASP.NET Core Identity fournit la gestion des comptes, des mots de passe, des rôles et des cookies de session. Il s'intégré au pipeline MVC et a EF Core, et permet de proteger des actions de contrôleur avec des attributs d'autorisation plutôt que d'écrire cette logique à la main.

Données et requêtes avancées

EF Core va bien au-delà des opérations simples vues pendant le projet : relations un-a-plusieurs et plusieurs-a-plusieurs, chargement explicite ou diffère, projections et requêtes optimisees. Maîtriser ces points évite les problèmes de performance quand le volume de données augmente.

Tests et deploiement

  • Les tests d'intégration avec WebApplicationFactory démarrent l'application en mémoire et verifient le comportement réel des routes, du modèle et de la base.
  • Le deploiement sur Azure App Service met l'application en ligne à partir du dépôt, avec une base hebergee et des variables d'environnement pour la configuration.

Autres pistes

Blazor permet d'écrire des interfaces de type application monopage directement en C#, en réutilisant les mêmes modèles que cote serveur. C'est une suite naturelle si vous souhaitez rester sur une seule technologie pour le front et le back.

Revenir au projet

Pour reprendre l'application MVC construite pendant le cours et y greffer ces sujets, repartez de la demo aspnet-mvc : ajouter l'authentification, enrichir les relations EF Core ou écrire un premier test d'intégration sont autant d'exercices concrets pour consolider les acquis.

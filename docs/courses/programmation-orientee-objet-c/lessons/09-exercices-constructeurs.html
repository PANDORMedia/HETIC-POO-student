Exercice 1 : Refactoriser Film avec un constructeur

Reprends ta classe Film et ajoute un constructeur paramétré qui accepte titre, realisateur et annee. Le champ genre aura une valeur par défaut "Non défini".

Supprime le constructeur par défaut (en définissant un constructeur paramétré, il disparaît automatiquement).

Dans Program.cs, crée 3 films avec le nouveau constructeur et affiche-les.

Validation : Tu ne peux plus créer un Film sans fournir titre, realisateur et annee.

public class Film
{
    public string titre;
    public string realisateur;
    public int annee;
    public string genre;

    // Ajouter le constructeur ici

    public void Afficher()
    {
        Console.WriteLine($"{titre} ({annee}) - {realisateur} [{genre}]");
    }
}
Solution
public class Film
{
    public string titre;
    public string realisateur;
    public int annee;
    public string genre;

    public Film(string titre, string realisateur, int annee)
    {
        this.titre = titre;
        this.realisateur = realisateur;
        this.annee = annee;
        this.genre = "Non défini";
    }

    public void Afficher()
    {
        Console.WriteLine($"{titre} ({annee}) - {realisateur} [{genre}]");
    }
}

// Program.cs
Film f1 = new Film("Inception", "Nolan", 2010);
Film f2 = new Film("Parasite", "Bong", 2019);
Film f3 = new Film("Le Grand Bleu", "Besson", 1988);
f1.Afficher();
f2.Afficher();
f3.Afficher();

Exercice 2 : Surcharge de constructeurs

Ajoute un deuxième constructeur à Film qui accepte aussi le genre. Le premier constructeur doit chaîner vers celui-ci avec :this().

// Constructeur 4 paramètres (principal)
public Film(string titre, string realisateur, int annee, string genre)
{
    // ...
}

// Constructeur 3 paramètres (délègue au 4 paramètres)
public Film(string titre, string realisateur, int annee)
    : this(titre, realisateur, annee, "Non défini")
{
}

Teste les deux formes.

Validation : new Film("Dune", "Villeneuve", 2021) et new Film("Dune", "Villeneuve", 2021, "Sci-Fi") fonctionnent tous les deux.

public class Film
{
    public string titre;
    public string realisateur;
    public int annee;
    public string genre;

    // Constructeur 4 paramètres
    public Film(string titre, string realisateur, int annee, string genre)
    {
        // À compléter
    }

    // Constructeur 3 paramètres avec chaînage
    // À compléter

    public void Afficher()
    {
        Console.WriteLine($"{titre} ({annee}) - {realisateur} [{genre}]");
    }
}
Solution
public class Film
{
    public string titre;
    public string realisateur;
    public int annee;
    public string genre;

    public Film(string titre, string realisateur, int annee, string genre)
    {
        this.titre = titre;
        this.realisateur = realisateur;
        this.annee = annee;
        this.genre = genre;
    }

    public Film(string titre, string realisateur, int annee)
        : this(titre, realisateur, annee, "Non défini")
    {
    }

    public void Afficher()
    {
        Console.WriteLine($"{titre} ({annee}) - {realisateur} [{genre}]");
    }
}

// Program.cs
Film f1 = new Film("Dune", "Villeneuve", 2021, "Sci-Fi");
Film f2 = new Film("Parasite", "Bong", 2019);
f1.Afficher(); // Dune (2021) - Villeneuve [Sci-Fi]
f2.Afficher(); // Parasite (2019) - Bong [Non défini]

Exercice 3 : Classe Categorie

Crée une classe Categorie avec :

  • Champs : nom (string), description (string)
  • Un constructeur qui prend seulement le nom (description par défaut : vide)
  • Un constructeur qui prend nom et description
  • Une méthode Afficher()

Crée 3 catégories de différentes façons.

Validation : Les catégories s'affichent correctement quelle que soit la forme utilisée.

public class Categorie
{
    // À compléter
}
Solution
public class Categorie
{
    public string nom;
    public string description;

    public Categorie(string nom, string description)
    {
        this.nom = nom;
        this.description = description;
    }

    public Categorie(string nom)
        : this(nom, "")
    {
    }

    public void Afficher()
    {
        Console.WriteLine($"{nom} : {description}");
    }
}

// Program.cs
Categorie c1 = new Categorie("Science-Fiction");
Categorie c2 = new Categorie("Thriller", "Films à suspense");
Categorie c3 = new Categorie("Drame", "Films dramatiques et émotionnels");
c1.Afficher(); // Science-Fiction : 
c2.Afficher(); // Thriller : Films à suspense

Exercice 4 : Initialisateur d'objet

Ajoute un constructeur sans paramètres à Categorie (en plus des deux existants). Ensuite, utilise la syntaxe d'initialisateur d'objet :

Categorie c = new Categorie
{
    nom = "Animation",
    description = "Films d'animation"
};

Crée aussi une Categorie avec le constructeur paramétré, et compare les deux syntaxes.

Question : Dans quel cas préférer l'initialisateur d'objet plutôt que le constructeur paramétré ?

Validation : Tu comprends quand chaque syntaxe est appropriée.

// Ajouter un constructeur sans paramètres à Categorie
// puis tester les 3 formes de création
Solution
public class Categorie
{
    public string nom;
    public string description;

    public Categorie() { }

    public Categorie(string nom, string description)
    {
        this.nom = nom;
        this.description = description;
    }

    public Categorie(string nom)
        : this(nom, "")
    {
    }
}

// 3 formes de création :
Categorie c1 = new Categorie("Sci-Fi", "Science-fiction");          // Constructeur
Categorie c2 = new Categorie { nom = "Animation", description = "Dessins animés" }; // Initialisateur
Categorie c3 = new Categorie(); c3.nom = "Thriller";                   // Manuelle

// L'initialisateur est préférable quand il y a beaucoup de champs optionnels
// et qu'on veut une syntaxe lisible sans multiplier les constructeurs.

Exercice 5 : Constructeur primaire (C# 12)

Réécris la classe Film en utilisant un constructeur primaire. Expose les paramètres via des propriétés en expression-bodied form :

public class Film(string titre, string realisateur, int annee, string genre = "Non défini")
{
    public string Titre => titre;
    // ...
}

Crée des films et vérifie que tout fonctionne comme avant.

Question : Quels sont les avantages et inconvénients du constructeur primaire par rapport au constructeur classique ?

Validation : Tu sais expliquer quand utiliser un constructeur primaire vs classique.

public class Film(string titre, string realisateur, int annee, string genre = "Non défini")
{
    // À compléter : exposer via propriétés
}
Solution
public class Film(string titre, string realisateur, int annee, string genre = "Non défini")
{
    public string Titre => titre;
    public string Realisateur => realisateur;
    public int Annee => annee;
    public string Genre => genre;

    public void Afficher()
    {
        Console.WriteLine($"{Titre} ({Annee}) - {Realisateur} [{Genre}]");
    }
}

// Program.cs
Film f1 = new Film("Inception", "Nolan", 2010, "Sci-Fi");
Film f2 = new Film("Parasite", "Bong", 2019);
f1.Afficher();
f2.Afficher();

// Avantages : syntaxe concise, moins de boilerplate
// Inconvénients : pas de validation dans le constructeur,
// les paramètres sont capturés (attention aux closures),
// moins flexible pour les initialisations complexes.

Exercice 1 : Créer la classe Film

Crée un fichier Film.cs avec :

  • Champs publics : titre (string), realisateur (string), annee (int), genre (string)
  • Une méthode Afficher() qui affiche : Titre (Année) - Réalisateur [Genre]
  • Une méthode Age() qui retourne l'âge du film (année actuelle - année du film)

Dans Program.cs, crée 3 films de ton choix et affiche-les.

Validation : Les 3 films s'affichent correctement et leur âge est cohérent.

// Film.cs
public class Film
{
    // À compléter
}
Solution
public class Film
{
    public string titre;
    public string realisateur;
    public int annee;
    public string genre;

    public void Afficher()
    {
        Console.WriteLine($"{titre} ({annee}) - {realisateur} [{genre}]");
    }

    public int Age()
    {
        return DateTime.Now.Year - annee;
    }
}

// Program.cs
Film f1 = new Film();
f1.titre = "Inception";
f1.realisateur = "Christopher Nolan";
f1.annee = 2010;
f1.genre = "Science-Fiction";

Film f2 = new Film();
f2.titre = "Parasite";
f2.realisateur = "Bong Joon-ho";
f2.annee = 2019;
f2.genre = "Thriller";

Film f3 = new Film();
f3.titre = "Le Grand Bleu";
f3.realisateur = "Luc Besson";
f3.annee = 1988;
f3.genre = "Drame";

f1.Afficher();
f2.Afficher();
f3.Afficher();

Console.WriteLine($"Age de f1 : {f1.Age()} ans");
Console.WriteLine($"Age de f3 : {f3.Age()} ans");

Exercice 2 : Créer la classe Utilisateur

Crée un fichier Utilisateur.cs avec :

  • Champs : nom (string), email (string)
  • Un champ filmsPreferes de type Film[] (tableau de 10 max)
  • Un champ nombreFilms (int) pour suivre le nombre de films ajoutés
  • Une méthode AjouterFilm(Film f) qui ajoute un film au tableau (si pas plein)
  • Une méthode AfficherListe() qui affiche tous les films préférés

Crée un utilisateur, ajoute les 3 films de l'exercice 1 et affiche sa liste.

Validation : La liste affiche les 3 films.

// Utilisateur.cs
public class Utilisateur
{
    // À compléter
}
Solution
public class Utilisateur
{
    public string nom;
    public string email;
    public Film[] filmsPreferes = new Film[10];
    public int nombreFilms = 0;

    public void AjouterFilm(Film f)
    {
        if (nombreFilms >= 10)
        {
            Console.WriteLine("Liste pleine !");
            return;
        }
        filmsPreferes[nombreFilms] = f;
        nombreFilms++;
    }

    public void AfficherListe()
    {
        Console.WriteLine($"Films de {nom} :");
        for (int i = 0; i < nombreFilms; i++)
        {
            Console.Write($"  {i + 1}. ");
            filmsPreferes[i].Afficher();
        }
    }
}

Exercice 3 : Comportement entre objets

Ajoute à Film une méthode EstPlusRecentQue(Film autre) qui retourne true si le film courant est plus récent que l'autre.

Ajoute aussi EstDeLaMemePeriode(Film autre) qui retourne true si les deux films sont sortis à moins de 5 ans d'écart.

Teste avec tes 3 films.

Validation : Les comparaisons retournent les bons booléens.

// Dans Film.cs
public bool EstPlusRecentQue(Film autre)
{
    // À compléter
}

public bool EstDeLaMemePeriode(Film autre)
{
    // À compléter
}
Solution
public bool EstPlusRecentQue(Film autre)
{
    return this.annee > autre.annee;
}

public bool EstDeLaMemePeriode(Film autre)
{
    return Math.Abs(this.annee - autre.annee) <= 5;
}

// Test dans Program.cs
Console.WriteLine($"{f1.titre} plus récent que {f3.titre} ? {f1.EstPlusRecentQue(f3)}");  // true
Console.WriteLine($"{f1.titre} même période que {f2.titre} ? {f1.EstDeLaMemePeriode(f2)}"); // true
Console.WriteLine($"{f1.titre} même période que {f3.titre} ? {f1.EstDeLaMemePeriode(f3)}"); // false

Exercice 4 : Comprendre les références

Sans exécuter le code, prédis ce que chaque Console.WriteLine affiche :

Film a = new Film();
a.titre = "Dune";
a.annee = 2021;

Film b = a;
b.titre = "Dune 2";

Console.WriteLine(a.titre);   // ???
Console.WriteLine(b.titre);   // ???
Console.WriteLine(a == b);    // ???

Film c = new Film();
c.titre = "Dune 2";
c.annee = 2021;

Console.WriteLine(a == c);    // ???
Console.WriteLine(a.titre == c.titre);  // ???

Vérifie ensuite en exécutant. Explique chaque résultat.

Validation : Tu peux expliquer pourquoi a == b est true mais a == c est false.

Solution
Console.WriteLine(a.titre);   // "Dune 2" (a et b pointent vers le même objet)
Console.WriteLine(b.titre);   // "Dune 2"
Console.WriteLine(a == b);    // True (même référence)
Console.WriteLine(a == c);    // False (objets différents)
Console.WriteLine(a.titre == c.titre);  // True (même valeur de string)

// a et b sont deux variables qui pointent vers LE MÊME objet en mémoire.
// c est un NOUVEL objet, même si le contenu est identique.
// == sur des références compare l'adresse, pas le contenu.

Exercice 5 : Mini-défi : classe FilmCollection

Crée une classe FilmCollection avec :

  • Un champ privé films de type List<Film> (utilise System.Collections.Generic)
  • Une méthode Ajouter(Film f) qui ajoute un film
  • Une méthode Tous() qui affiche tous les films
  • Une méthode RechercherParAnnee(int annee) qui retourne tous les films de cette année
  • Une méthode PlusRecent() qui retourne le film le plus récent

Teste avec 5+ films.

Validation : La recherche par année et le film le plus récent fonctionnent correctement.

using System.Collections.Generic;

public class FilmCollection
{
    // À compléter
}
Solution
using System.Collections.Generic;

public class FilmCollection
{
    private List<Film> films = new List<Film>();

    public void Ajouter(Film f)
    {
        films.Add(f);
    }

    public void Tous()
    {
        foreach (Film f in films)
        {
            f.Afficher();
        }
    }

    public List<Film> RechercherParAnnee(int annee)
    {
        List<Film> resultats = new List<Film>();
        foreach (Film f in films)
        {
            if (f.annee == annee)
                resultats.Add(f);
        }
        return resultats;
    }

    public Film PlusRecent()
    {
        if (films.Count == 0) return null;
        Film plusRecent = films[0];
        foreach (Film f in films)
        {
            if (f.EstPlusRecentQue(plusRecent))
                plusRecent = f;
        }
        return plusRecent;
    }
}

Démo formateur : Héritage, Polymorphisme & Interfaces

Script de démonstration live pour le formateur. Durée : ~25 min.

Objectif : montrer la construction progressive de la hiérarchie Media du gestionnaire de films.

Étape 1 : Classe de base Media

Créez un nouveau projet console et codez la classe Media en direct.

Points à souligner :

  • Titre et Annee comme propriétés publiques
  • Constructeur avec paramètres
  • GetInfo() comme méthode simple
  • ToString() override
// DemoHeritage/Program.cs

public class Media
{
    private static int _compteur = 0;
    public int Id { get; }
    public string Titre { get; set; }
    public int Annee { get; set; }

    public Media(string titre, int annee)
    {
        Id = ++_compteur;
        Titre = titre;
        Annee = annee;
    }

    public virtual string GetInfo() => $"{Titre} ({Annee})";
    public override string ToString() => $"[{Id}] {GetInfo()}";
}

Étape 2 : Film et Serie héritent de Media

Ajoutez les classes dérivées. Montrez :

  • L'opérateur : pour l'héritage
  • base() pour chaîner les constructeurs
  • L'ajout de propriétés spécifiques
  • L'override de ToString()
public class Film : Media
{
    public string Realisateur { get; set; }
    public int DureeMinutes { get; set; }
    public string Genre { get; set; }

    public Film(string titre, int annee, string realisateur, int duree, string genre)
        : base(titre, annee)
    {
        Realisateur = realisateur;
        DureeMinutes = duree;
        Genre = genre;
    }

    public override string GetInfo()
        => $"{Titre} ({Annee}) - {Realisateur}, {DureeMinutes} min";
}

public class Serie : Media
{
    public int Saisons { get; set; }
    public int EpisodesParSaison { get; set; }

    public Serie(string titre, int annee, int saisons, int episodes)
        : base(titre, annee)
    {
        Saisons = saisons;
        EpisodesParSaison = episodes;
    }

    public int NombreTotalEpisodes => Saisons * EpisodesParSaison;
    public override string GetInfo()
        => $"{Titre} ({Annee}) - {Saisons} saisons ({NombreTotalEpisodes} épisodes)";
}

Étape 3 : Démontrer le polymorphisme

Créez une liste mixte et montrez le dispatch dynamique. Modifiez GetInfo() en live pour montrer que le changement se propage.

// Polymorphisme en action
List<Media> catalogue = new()
{
    new Film("Dune", 2021, "Villeneuve", 155, "Sci-Fi"),
    new Serie("Severance", 2022, 2, 10),
    new Film("Parasite", 2019, "Bong Joon-ho", 132, "Thriller"),
    new Serie("Dark", 2017, 3, 10)
};

Console.WriteLine("=== Catalogue polymorphe ===");
foreach (var media in catalogue)
{
    Console.WriteLine(media);
    // Montre que GetInfo() appelle la bonne version
}

// Pattern matching
Console.WriteLine("\n=== Films uniquement ===");
foreach (var m in catalogue)
{
    if (m is Film film)
        Console.WriteLine($"{film.Titre} par {film.Realisateur}");
}

Étape 4 : Transformer en abstrait

Modifiez Media en abstract class et ajoutez CalculerPrix(). Montrez l'erreur de compilation si une dérivée oublie d'implémenter.

public abstract class Media
{
    private static int _compteur = 0;
    public int Id { get; }
    public string Titre { get; set; }
    public int Annee { get; set; }

    protected Media(string titre, int annee)
    {
        Id = ++_compteur;
        Titre = titre;
        Annee = annee;
    }

    public abstract string GetTypeMedia();
    public abstract decimal CalculerPrix();
    public virtual string GetInfo() => $"{Titre} ({Annee})";

    // Template Method
    public string GenererFiche()
        => $"#{Id} [{GetTypeMedia()}] {GetInfo()} - {CalculerPrix():C}";
}

// Dans Film :
public override string GetTypeMedia() => "Film";
public override decimal CalculerPrix() => DureeMinutes > 120 ? 14.99m : 9.99m;

Étape 5 : Interfaces et découplage

Ajoutez les interfaces IStreamable et INotable. Montrez l'implémentation multiple et le polymorphisme par interface.

public interface IStreamable
{
    string Plateforme { get; set; }
    bool EstDisponibleEnStreaming();
    string GetLienStreaming();
}

public interface INotable
{
    double Note { get; set; }
    void AttribuerNote(double note);
    string GetAvis();
}

// Film implémente les deux
public class Film : Media, IStreamable, INotable
{
    // ... propriétés existantes ...

    // IStreamable
    public string Plateforme { get; set; }
    public bool EstDisponibleEnStreaming() => !string.IsNullOrEmpty(Plateforme);
    public string GetLienStreaming() => $"https://{Plateforme?.ToLower()}.com/{Titre?.Replace(' ', '-')}";

    // INotable
    public double Note { get; set; }
    public void AttribuerNote(double note) => Note = Math.Clamp(note, 0, 10);
    public string GetAvis() => Note >= 7 ? "Recommandé" : Note >= 5 ? "Moyen" : "À éviter";
}

// Utilisation polymorphe par interface
List<INotable> notables = new()
{
    new Film("Dune", 2021, "Villeneuve", 155, "Sci-Fi"),
    new Film("Parasite", 2019, "Bong", 132, "Thriller")
};

((INotable)notables[0]).AttribuerNote(8.5);
((INotable)notables[1]).AttribuerNote(9.1);

foreach (var n in notables)
    Console.WriteLine($"{n.Note}/10 - {n.GetAvis()}");

Points à souligner pendant la démo

  1. L'héritage se fait avec :, pas extends
  2. base() est obligatoire quand le parent n'a pas de constructeur sans paramètres
  3. Le polymorphisme = même appel, comportement différent au runtime
  4. Abstract = contrat obligatoire + code partagé
  5. Interface = contrat pur, implémentation multiple
  6. Le Template Method est un usage classique des classes abstraites
  7. Les interfaces sont le fondement du découplage et de la testabilité

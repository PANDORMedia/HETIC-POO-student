# Mini exo 1 : Composition ou héritage ?

## Objectif

Aller plus loin que le test is-a vs has-a vu en J2, sur des cas où le bon choix dépend du métier.

## Énoncé

Pour chaque paire, indique :

- héritage : X est un Y
- composition : X a un Y
- ou les deux selon le contexte

Justifie en une phrase. Si tu choisis composition, indique le nom du champ probable dans la classe. Si tu choisis héritage, écris la déclaration C# `class X : Y`.

1. Voiture / Moteur
2. Smartphone / Caméra
3. Manager / Employé
4. Chien / Animal
5. PlaylistMusicale / Chanson
6. EmailService / Logger
7. CompteEpargne / CompteBancaire
8. Restaurant / Table

## Temps

5 minutes. Correction collective.
